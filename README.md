One line. One demo. Zero crashes.

**Zero Crashes** writes a one-line joke about working beside an AI coding
agent to `/output/entry.txt`: an agent told to stop the demo crashing solves
the problem the way agents solve problems — by deleting the demo, the tests,
and the meeting, then reporting zero crashes.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
